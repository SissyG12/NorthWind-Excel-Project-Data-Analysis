# Business Database Analysis with Excel PivotTables

## Overview
This project analyzes a company's internal database using Excel. Starting
from raw, unorganized data, I applied data cleaning techniques and a range
of Excel functions to structure the dataset and prepare it for analysis.
I then built PivotTables to extract key business insights and answer
specific analytical questions about the company's operations.

## Data
The dataset represents an internal business database used for coursework
purposes. Before cleaning, the data was unstructured, with inconsistent
formatting and missing values that needed to be addressed.

## Tools & Skills Used
- Excel formulas & functions for data cleaning
- PivotTables for aggregation and analysis
- Data structuring and formatting
